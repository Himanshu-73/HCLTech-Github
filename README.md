gi# repoMondayHclTech
repo practice

File status:
1. untracked - New files that git does not track yet.
2. tracked - Files that are being tracked by git.
3. modified - Files that have been changed but not yet staged.
4. staged - Files that are ready to be committed.
origin acts as an alias for the remote repository. or shorthand name for the URL of your remote repo.

Repo -> Local System -> Files -> Github
Folder -> 1. git init/git status
        ->2. git remote -v (to verify remote repo)
        ->3. git branch (to check the current branch)

        Repository (master> -> main) -> git branch -m main (to rename the branch)
